# Figma Dashboard Design Resources

This folder contains dashboard layout inspiration and design references that can be used before building a final Power BI report.

Use it to:
- brainstorm report structures
- create mockups and wireframes
- explore dashboard layouts
- test visual hierarchy before implementation
- align design decisions with business goals

## Suggested idea flow

Idea → Figma mockup → Power BI dashboard → final portfolio project

This folder is meant to help you plan the design stage more quickly without jumping straight into a full build.
