# Native Visuals

This directory contains examples built using only Power BI's native visuals.

Use this folder to study:
- layouts and spacing
- KPI design
- chart selection
- drill-down and filter behavior
- when native visuals are the best choice

## Good examples to include

- line chart
- bar chart
- column chart
- map
- matrix
- slicer
- KPI card

This section is especially useful for learning how clear and professional a dashboard can look without custom visuals.
