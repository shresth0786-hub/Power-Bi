# Full Dashboards

This folder is reserved for complete Power BI dashboard examples.

Use it to store:
- finished `.pbix` files
- supporting datasets
- screenshots of final reports
- notes explaining business context and report design decisions

## Recommended structure

- `dashboard-name/`
- `images/`
- `data/`
- `README.md`

Create one subfolder per dashboard to keep the project organized and portfolio-friendly.
