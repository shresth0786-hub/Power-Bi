# Theme JSON Files

This folder stores reusable Power BI theme files.

Theme files help standardize:
- color palette
- background and foreground colors
- title and label formatting
- font selections
- visual consistency across dashboards

## Suggested file naming

- `dark-theme.json`
- `light-theme.json`
- `retail-dashboard-theme.json`
- `executive-theme.json`

Use consistent naming and document when each theme is appropriate.
